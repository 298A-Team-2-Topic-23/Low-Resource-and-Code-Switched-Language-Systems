## Known errors a 298B reader should not repeat

- **Section 3.6 quotes superseded synthetic fertility numbers** (1.024 / 1.501, 98.5% / 52.6%).
  Use `reports/fertility.csv` (1.154 / 1.653), and do not quote the coverage contrast at all
  (`carry_forward.md`). `python scripts/audit_section_3_6.py` reports the mismatches.
- **The README quickstart overwrites the real-corpus statistics** with synthetic ones. Check
  `git status` before committing anything under `reports/`.
- **`results/results.jsonl` holds smoke-test numbers** on synthetic data with a 0.5B model. They
  are not M1 or M2 results.
- **The code-mix output is not GCM output.** It uses monotonic alignment blocks, not a parser, and
  must not be reported as GCM.
- **HinGE's reference count is 4,799.** The 4,803 in the paper's text does not match the paper's
  own table (298-77).
