## Workflow

1. Move your issue to **In Progress today**
2. Branch: `<yourname>/298-XX-<slug>`
3. Commit: `Refs 298-XX: what you did`
4. PR body: **`Closes 298-XX`** — this is what links it to Linear
5. Request a review from someone who is not you
6. On merge, attach the PR and move to Done

**An issue closes only with a linked artifact.** This is the thing we have been weakest on
all semester, and 298-60 finally turns on the gate that enforces it.
