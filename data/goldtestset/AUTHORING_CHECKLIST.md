# Gold-set authoring checklist

- [ ] Confirm the pilot alpha result for both adequacy and fluency.
- [ ] Record the reconciliation decision and any guideline revision.
- [ ] Import only an approved English source inventory with stable `item_id` values.
- [ ] Write Devanagari Hindi and Romanized Hinglish independently.
- [ ] Preserve natural Romanized spelling; do not normalise variants.
- [ ] Flag uncertain items and record the reason in `notes`.
- [ ] Run `validate_gold_set.py` with the frozen item count.
- [ ] Have a second teammate review flagged rows and a sample of unflagged rows.
- [ ] Record the final row count and validation command in the project report.
